⚠️ Problèmes Identifiés & Solutions

🚨 ISSUE #1 : Champ "Objet" Très Faible (F1 0.067)
Impact: 100% des documents - Exact Match 0%
Racine: Texte libre non-structuré, pas de pattern fixe
Court-Terme: Augmenter données (300+ exemples), fine-tuner SpaCy
Projeté: F1 0.067 → 0.35-0.50 (3 mois) → 0.70+ (12 mois)
Priorité: 🔴 CRITIQUE
⚠️ ISSUE #2 : Ref Code Sensible OCR (F1 0.697)
Racine: Confusion OCR (1↔l, 0↔O, S↔5)
Solution: Normalisation layer + patterns augmentés
Projeté: F1 0.697 → 0.80+
Priorité: 🟠 HAUTE
⚠️ ISSUE #3 : Destination Multi-Ligne (F1 0.801)
Racine: Adresses sur 2-4 lignes, variations délimiteurs
Solution: Améliorer contexte délimiteurs, tolérance SpaCy GPE
Projeté: F1 0.801 → 0.85+
Priorité: 🟡 MOYENNE
⚠️ ISSUE #4 : Outliers OCR (CER > 40%)
Quantité: 3 documents sur 142 (2.1%)
Racine: Qualité scan dégradée, PDF bas-résolution
Solution: Pré-traitement amélioré, upscaling image
Projeté: 3 outliers → 1 outlier
Priorité: 🟡 MOYENNE
⚠️ ISSUE #5 : Exact Match Content Bas (13.4%)
Racine: Texte long, tolérance variation OCR
Solution: Partial matching + segmentation phrase
Projeté: 13.4% → 60%+
Priorité: 🔵 BASSE
